# Winnipeg time-zone data

IANA 2026e, vendored from the official Python tzdata repository because the published tzdata 2026.4 package contains 2026d. This replaces the older Winnipeg data for the calling-time feature, including its northwestern Ontario city mappings. No hand-written clock-transition rules.
